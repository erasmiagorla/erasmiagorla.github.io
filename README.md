# Erasmia Gorla Raphael — one-page CV website

This is a free GitHub Pages/Jekyll site. Its homepage displays your CV directly, and the PDF download is your original two-page CV.

## Publish

1. Unzip `erasmia-cv-website.zip`.
2. Visit https://github.com/erasmiagorla/erasmiagorla.github.io
3. Click **Add file > Upload files**, and upload the **contents** of the unzipped folder, preserving folder names. Commit the changes.
4. Go to **Settings > Pages**. Choose **Deploy from a branch**, `main`, `/(root)`, and save. Wait for the Pages deployment to finish.
5. Open https://erasmiagorla.github.io

If you uploaded the earlier multi-page starter, remove its older pages (`research.md`, `publications.md`, `cv.md`, and `contact.md`). This package replaces the prior `index.md`, layout, and CSS. Don't leave a separate `index.html` at the repository root: that could take priority over `index.md`.

## Update your site

- To edit the words visitors see, open `index.md` on GitHub and click the pencil icon. Save with **Commit changes**. No HTML knowledge needed: content is Markdown.
- To update the downloadable PDF, export the newest CV from Word to PDF, name it `Erasmia_Gorla_Raphael_CV.pdf`, and replace the file in the `assets` folder.
- Updating the PDF **does not automatically update** the webpage text, or vice versa. Update both when the CV changes.
- The visual design lives in `assets/style.css`. The page layout lives in `_layouts/default.html`.
- These are publicly visible files. Don't add private addresses, phone numbers, or sensitive information.
- Your purchased custom domain can be connected later in **Settings > Pages**, following the GitHub Pages custom-domain directions.
