# Academic website starter

A free, minimalist Jekyll website designed for GitHub Pages.

## Put it on GitHub

1. Unzip the downloaded archive.
2. Visit https://github.com/erasmiagorla/erasmiagorla.github.io
3. Choose **Add file > Upload files**.
4. Drag the CONTENTS of this folder into the upload area (including the `_layouts` and `assets` folders; do not upload the outer folder).
5. Click **Commit changes**. If GitHub does not preserve folders when you upload, you can use its web editor to create files with those paths, or upload via GitHub Desktop.
6. In **Settings > Pages**, set Source to **Deploy from a branch**, Branch to **main**, folder to **/(root)**, and save.
7. Visit https://erasmiagorla.github.io after GitHub completes its Pages build.

## Edit your website yourself

- `_config.yml`: Your public full professional name, subtitle, and site description.
- `index.md`: Home page.
- `research.md`: Research page.
- `publications.md`: Publications and presentations.
- `cv.md`: Curriculum vitae page.
- `contact.md`: Contact page.
- `assets/style.css`: Fonts, colors, spacing, and design.
- `_layouts/default.html`: Shared navigation and HTML layout.

On GitHub, open a file, click the pencil icon, edit it, and select **Commit changes**.
You can write normal Markdown in the `.md` pages.

## Connect your purchased domain (later)

In Settings > Pages, save the custom domain first. Then update DNS at your domain registrar following GitHub's official documentation:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

Do not put a placeholder domain in the Pages custom-domain setting.

## Notes

- No paid services, fonts, analytics, or trackers are used.
- All content in a public GitHub Pages repository is public, including PDFs you upload.
- The text in the research pages is a draft and can be revised before publicity.
- Site styling uses only CSS and locally available fonts; no dependency on commercial website builders.
